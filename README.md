# my-simple-webpage
Create your repository

Sign in to GitHub and create a new public repository named my-simple-webpage.
Select Add a README file, then create the repository.
Confirm that you are on the main branch.
Add Markdown examples

Search the web for “markdown examples”.
Use examples you find to learn the Markdown syntax, then edit README.md and include each of the following:
A bullet list.
A numbered list.
Some italic text.
Some bold text.
Preview the README to check that the lists, italic text, and bold text display correctly.
Commit the changes directly to main with a short message, such as Add Markdown examples.
Download and upload a webpage

Download index.html and save it on your computer. If the link opens a webpage instead, right-click the link and choose Save Link As. Keep the filename index.html.
Return to the main file list of your my-simple-webpage repository on GitHub.
Select Add file → Upload files and choose the downloaded index.html file.
Commit the upload directly to main with a short message, such as Upload index.html.
For help with uploading, see GitHub’s upload instructions.
